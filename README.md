# Cantrell Auto Detailing

Modern, professional, and clean website for Cantrell's Auto Detailing.

## Tech Stack
- Astro
- Tailwind CSS

## Branding & Design
- **Core Vibe:** Clean, High-End, Industrial but Polished
- **Color Palette:** Slate-950 (Night), Blue-600 (Rinse), Zinc-100 (Clean)
- **Fonts:**
  - **Montserrat:** Bold, geometric sans-serif for headers (professional & industrial).
  - **Inter:** Highly readable sans-serif for body text (modern & clean).
  - **JetBrains Mono:** For small accents or technical specs (reflects precision/detailing).
